# ai-journal-ledger-validator-transaction-trial-balance-checker-
AI-assisted accounting project where 10-15 raw transactions are given to AI to generate general journal entries. Validated entries in General Ledger and Trial Balance to check if debit=credit. Identified errors and ensured accurate ledger, trial balance, income statement and balance sheet reporting.
